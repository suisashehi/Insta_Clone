# Pixelle – Image Blog

A full-stack image sharing platform built with SvelteKit, Tailwind CSS, MySQL and Vercel Blob.

## Features
- Register and login with secure sessions
- Upload photos with CSS filters
- Like, comment and bookmark photos
- User profiles with photos and comments tab
- Report comments and block users
- Admin panel for managing users, images and reports
- Dark mode toggle
- Fully responsive

## Tech Stack
- SvelteKit
- Tailwind CSS
- MySQL
- Vercel Blob

## Setup
1. Clone the repo
2. Copy `.env.example` to `.env` and fill in your values
3. Run `npm install`
4. Run the SQL from `database/schema.sql` in your database
5. Run `npm run dev`
